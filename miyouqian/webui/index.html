多账号时，跑完一个账号先等一会儿再跑下一个，让它们看起来像不同时段各自操作的。 想连着跑就把上面的开关关掉，或者把两个值都填 0。

验证码识别 默认关闭，启用请配置打码平台

「本地识别」需要本机装有 Chrome / Edge：自检会真实启动一次浏览器并打开识别测试页， 几秒内完成，不碰账号、不下载模型。装了 Docker 的服务器里通常没有浏览器，会显示失败原因。

IP 防护 境外 IP 时暂停签到

会分别检测「国内直连」和「境外流量」两条链路的出口 IP：分流模式（规则模式）的代理下， 米游社作为境外服务走的是代理那条路，只看国内出口会漏判。
